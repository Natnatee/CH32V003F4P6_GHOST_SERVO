# CH32V003_CHECK (PIR → IR 38kHz → MG90S)

## โค้ดปัจจุบัน: IR แทน RF
- ตัวส่ง: AM312 PC1 → IR LED ผ่านวงจรขับ Active HIGH ที่ **PC4 ขาชิป14**; LED PC2 ติด3s/พัก3s
- ตัวรับ: **demodulated IR38kHz OUT Active LOW → PC4 ขาชิป14**; MG90S PD2 ไป–กลับประมาณ160° ค้าง5s กลับแล้วพัก10s
- ตัวรับ IR รุ่นจริงยังไม่ทราบ ต้องตรง38kHz/Active LOW และแรงดันลอจิกที่เหมาะสม ไม่ใช่ photodiode เปล่าหรือ obstacle sensor
- ห้ามต่อ IR LED เปล่าตรง GPIO ต้องจำกัดกระแสและใช้วงจรขับที่เหมาะสม

แฟลชทีละบอร์ด:
```bash
pio run -d transmitter -e ch32v003f4p6 -t upload
pio run -d receiver -e ch32v003f4p6 -t upload
```
ทดสอบโดยไม่ใช้ PIR/servo ใช้ `-e ir_test` แทนทั้งสองฝั่ง ดูคู่มือล่าสุดใน `transmitter/README.md` และ `receiver/README.md` คอมไพล์ผ่าน ยังไม่ยืนยันบน IR จริง

## ประวัติ RF / Servo / Blink ด้านล่าง (ไม่ใช่โค้ดปัจจุบัน)

## ทดสอบ RF อย่างเดียว
เพิ่มโหมด `rf_test` โดยไม่เปลี่ยนค่าปริยายโหมดเดิม:
```bash
pio run -d transmitter -e rf_test -t upload
pio run -d receiver -e rf_test -t upload
```
ต่อโปรแกรมเมอร์กับบอร์ดเป้าหมายทีละตัว ฝั่งส่งทำงานเองไม่รอ PIR; ฝั่งรับไม่ขยับเซอร์โวและแสดง timing log ดูวิธีอ่านและกลับโหมดเดิมใน `receiver/README.md`

ผู้ใช้ยืนยัน MCU ฝั่งรับเลี้ยง **5V**: RF DATA เข้า PC4 ตรง ไม่ใช้ divider ตามคำแนะนำเก่าที่สมมติ 3.3V แยกไฟ/GND ข้ามฝั่งเช่นเดิม (แต่ร่วม GND อุปกรณ์ภายในแต่ละฝั่ง)

## ชุด RF 433MHz + AM312 + MG90S
- [`transmitter/`](transmitter/README.md): ฝั่งส่ง PIR PC1 → RF TX PC4
- [`receiver/`](receiver/README.md): RF RX PC4 → MG90S PD2 หมุนออกประมาณ 90° ค้าง 5s กลับ แล้วพัก 10s
- คอมไพล์แยก: `pio run -d transmitter` และ `pio run -d receiver`
- แฟลชแยก: `pio run -d transmitter -t upload` หรือ `pio run -d receiver -t upload` โดยต่อเฉพาะบอร์ดเป้าหมาย
- ดูวงจรลดแรงดัน DATA ตัวรับในคู่มือก่อนต่อ ยังไม่ยืนยันผล RF บนฮาร์ดแวร์

## การทดสอบเดิมใน root
เฟิร์มแวร์ `src/main.c` เปลี่ยนเป็น MG90S หมุนไป–กลับประมาณ 0–90° แล้ว ไม่ใช่ Blink LED ตามเอกสารเดิมด้านล่าง

```text
บอร์ด CH32V003 (ดูชื่อขาบนบอร์ด)
+------------------+
| PD2 -------------|---- MG90S ส้ม/เหลือง (Signal)
| GND -------------|--+-- MG90S น้ำตาล (GND)
+------------------+  |
ไฟแยก 5V ลบ ----------+
ไฟแยก 5V บวก ------------ MG90S แดง (VCC)
```

- ใช้ไฟแยก 5V แนะนำอย่างน้อย 1A และต่อ GND ร่วม ห้ามใช้ 3.3V จากโปรแกรมเมอร์เลี้ยงเซอร์โว
- pulse 1000–1500µs ที่ 50Hz; มุมจริงต้องตรวจบนเซอร์โว ทดลองโดยไม่ติดโหลดก่อน
- ไปแต่ละทิศประมาณ 2 วินาที พักปลายทาง 0.5 วินาที
- ดูผังขาชิปใน `project.md`; ยังไม่ทดสอบเซอร์โวจริง
- คอมไพล์: `pio run` / แฟลชด้วยตนเอง: `pio run -t upload`

## เอกสาร Blink เดิม (ประวัติ ไม่ใช่เฟิร์มแวร์ปัจจุบัน)

โปรเจกต์เริ่มต้นสำหรับการเซ็ตอัพ ตรวจสอบความถูกต้องในการประกอบฮาร์ดแวร์ และเบิร์นเฟิร์มแวร์ไฟกระพริบ (Blink LED) ลงในไมโครคอนโทรลเลอร์ **CH32V003F4P6** สถาปัตยกรรม RISC-V 32-bit ด้วยคอมมูนิตี้แพลตฟอร์ม **`ch32v`** และเฟรมเวิร์ก **`ch32v003fun`** บนระบบ **PlatformIO**

## Features
- ไฟกระพริบ (Blink LED) ที่ขา **`PD6`** เพื่อตรวจสอบสถานะการทำงานของ MCU
- ตั้งค่าระบบคล็อกเริ่มต้นด้วย `SystemInit()` ของ `ch32v003fun`
- วิธีดีบั๊กและสั่งงานผ่าน PlatformIO CLI

## Hardware
1. บอร์ดพัฒนาหรือตัวชิปเดี่ยว **CH32V003F4P6**
2. เครื่องโปรแกรมและดีบั๊ก **WCH-LinkE**
3. LED ขนาดเล็กและตัวต้านทานจำกัดกระแส (ต่อเข้ากับขา PD6)

## Pin Map

| Function | Pin | Notes |
|---|---|---|
| SWDIO / SDI | PD1 | สายสัญญาณสำหรับอัปโหลดข้อมูล (ต่อเข้ากับขา SWDIO ของ WCH-LinkE) |
| LED | PD6 | ขาควบคุมไฟกระพริบ (Active High) |
| VCC | 3.3V | แรงดันไฟเลี้ยงระบบ |
| GND | GND | สายกราวด์ร่วมกัน |

## Wiring Notes
- **WCH-LinkE -> CH32V003F4P6**
  - `3.3V`  -> `VCC`
  - `GND`   -> `GND`
  - `SWDIO` -> `PD1` (หรือขาสัญญาณ SDI)

## Getting Started

เปิด Terminal ในโฟลเดอร์โปรเจกต์นี้และใช้คำสั่ง PlatformIO CLI ในการทำงาน:

1. **ดาวน์โหลดทูลและคอมไพล์โปรเจกต์ครั้งแรก:**
   ```bash
   pio run
   ```
2. **อัปโหลดเฟิร์มแวร์ลงบนชิป (ด้วย WCH-LinkE):**
   ```bash
   pio run -t upload
   ```
3. **คลีนและคอมไพล์ใหม่:**
   ```bash
   pio run -t clean
   pio run
   ```
