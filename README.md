# CH32V003_CHECK (Blink LED)

โปรเจกต์เริ่มต้นสำหรับการเซ็ตอัพ ตรวจสอบความถูกต้องในการประกอบฮาร์ดแวร์ และเบิร์นเฟิร์มแวร์ไฟกระพริบ (Blink LED) ลงในไมโครคอนโทรลเลอร์ **CH32V003F4P6** สถาปัตยกรรม RISC-V 32-bit ด้วยคอมมูนิตี้แพลตฟอร์ม **`ch32v`** และเฟรมเวิร์ก **`ch32v003fun`** บนระบบ **PlatformIO**

## Features
- ไฟกระพริบ (Blink LED) ที่ขา **`PD6`** เพื่อตรวจสอบสถานะการทำงานของ MCU
- ตั้งค่าระบบคล็อกเริ่มต้นด้วย `SystemInit()` ของ `ch32v003fun`
- วิธีดีบั๊กและสั่งงานผ่าน PlatformIO CLI

## Hardware
1. บอร์ดพัฒนาหรือตัวชิปเดี่ยว **CH32V003F4P6**
2. เครื่องโปรแกรมและดีบั๊ก **WCH-LinkE**
3. LED ขนาดเล็กและตัวต้านทานจำกัดกระแส (ต่อเข้ากับขา PD6)

## Pin Map

| Function | Pin | Notes |
|---|---|---|
| SWDIO / SDI | PD1 | สายสัญญาณสำหรับอัปโหลดข้อมูล (ต่อเข้ากับขา SWDIO ของ WCH-LinkE) |
| LED | PD6 | ขาควบคุมไฟกระพริบ (Active High) |
| VCC | 3.3V | แรงดันไฟเลี้ยงระบบ |
| GND | GND | สายกราวด์ร่วมกัน |

## Wiring Notes
- **WCH-LinkE -> CH32V003F4P6**
  - `3.3V`  -> `VCC`
  - `GND`   -> `GND`
  - `SWDIO` -> `PD1` (หรือขาสัญญาณ SDI)

## Getting Started

เปิด Terminal ในโฟลเดอร์โปรเจกต์นี้และใช้คำสั่ง PlatformIO CLI ในการทำงาน:

1. **ดาวน์โหลดทูลและคอมไพล์โปรเจกต์ครั้งแรก:**
   ```bash
   pio run
   ```
2. **อัปโหลดเฟิร์มแวร์ลงบนชิป (ด้วย WCH-LinkE):**
   ```bash
   pio run -t upload
   ```
3. **คลีนและคอมไพล์ใหม่:**
   ```bash
   pio run -t clean
   pio run
   ```

## Safety
- ก่อนเชื่อมต่อสาย ให้แน่ใจว่าอุปกรณ์คอมพิวเตอร์และตัวชิปไม่มีการจ่ายไฟค้างอยู่
- อย่าเชื่อมต่อแหล่งจ่ายไฟภายนอกเข้ากับพอร์ต VCC ในขณะที่ใช้ไฟเลี้ยงจาก WCH-LinkE เพื่อความปลอดภัยของพอร์ต USB บนคอมพิวเตอร์ของคุณ
